برای **دریافت و بارگذاری دیتاست با pandas** معمولاً از توابع زیر استفاده می‌شود:

- **pd.read_csv()**: بارگذاری فایل CSV به دیتافریم  
  ```python
  import pandas as pd
  df = pd.read_csv('file.csv')
  ```
  این تابع بسیار انعطاف‌پذیر است و می‌توانید پارامترهایی مثل جداکننده، اندیس، ستون‌های خاص و ... را تنظیم کنید[10].

- **pd.read_excel()**: بارگذاری فایل Excel  
  ```python
  df = pd.read_excel('file.xlsx')
  ```

- **pd.read_json()**: بارگذاری فایل JSON  
  ```python
  df = pd.read_json('file.json')
  ```

- **pd.read_sql_query()**: بارگذاری داده‌ها از دیتابیس SQL با ارسال کوئری  
  ```python
  import sqlite3
  conn = sqlite3.connect('database.db')
  df = pd.read_sql_query('SELECT * FROM table_name', conn)
  ```
  این روش برای استخراج داده‌های خاص از دیتابیس بسیار کاربردی است[3].

- **pd.read_table()**: بارگذاری فایل متنی با جداکننده دلخواه (مثلاً تب)  
  ```python
  df = pd.read_table('file.txt', sep='\t')
  ```

همچنین برای مشاهده سریع داده‌ها پس از بارگذاری می‌توانید از متدهای زیر استفاده کنید:  
- `df.head()` برای نمایش چند سطر اول  
- `df.info()` برای مشاهده اطلاعات کلی دیتافریم  
- `df.describe()` برای آمار توصیفی ستون‌های عددی[2][5].

برای **حذف ستون‌های خالی در pandas** که شامل مقادیر گمشده (NaN) هستند، می‌توانید از تابع **`dropna()`** با آرگومان `axis=1` استفاده کنید. چند حالت مهم:

- حذف ستون‌هایی که **حداقل یک مقدار خالی دارند**:  
```python
df = df.dropna(axis=1, how='any')
```

- حذف ستون‌هایی که **تمام مقادیرشان خالی است**:  
```python
df = df.dropna(axis=1, how='all')
```

- اگر بخواهید تغییر روی خود DataFrame اعمال شود و نسخه جدید ساخته نشود، از `inplace=True` استفاده کنید:  
```python
df.dropna(axis=1, how='any', inplace=True)
```

**مثال کامل:**  
```python
import pandas as pd
import numpy as np

data = {'A': [1, 2, np.nan], 'B': [np.nan, np.nan, np.nan], 'C': [7, 8, 9]}
df = pd.DataFrame(data)

# حذف ستون‌هایی که همه مقادیرشان خالی است
df_clean = df.dropna(axis=1, how='all')
print(df_clean)
```

در این مثال ستون B که کاملاً خالی است حذف می‌شود، اما ستون A که فقط برخی مقادیرش خالی است باقی می‌ماند[1][5][6].

این روش ساده‌ترین و رایج‌ترین راه برای حذف ستون‌های خالی در pandas است.
--------------------------------------------------------------------------------------------------------------------------------------------
برای **حذف سطرهایی که دارای مقدار خالی (NaN) هستند** در pandas، از متد **`dropna()`** استفاده می‌شود که به صورت پیش‌فرض سطرهایی که حداقل یک مقدار خالی دارند را حذف می‌کند:

```python
df = df.dropna()
```

یا اگر بخواهید تغییر روی خود DataFrame اعمال شود:

```python
df.dropna(inplace=True)
```

- این دستور همه سطرهایی که در هر ستونی مقدار خالی دارند را حذف می‌کند.  
- اگر بخواهید فقط سطرهایی که تعداد مشخصی مقدار غیرخالی دارند را نگه دارید، می‌توانید از پارامتر `thresh` استفاده کنید. مثلاً:

```python
df.dropna(thresh=3, inplace=True)  # فقط سطرهایی که حداقل 3 مقدار غیرخالی دارند نگه می‌دارد
```

- برای حذف سطرهایی که در ستون خاصی مقدار خالی دارند، می‌توانید از پارامتر `subset` استفاده کنید:

```python
df.dropna(subset=['column_name'], inplace=True)
```

این روش ساده‌ترین و رایج‌ترین راه برای حذف سطرهای دارای مقادیر خالی در pandas است[1][2][5][6].

برخی از **تابع‌های معروف کتابخانه pandas** به همراه مثال‌های کاربردی به شرح زیر است:

- **pd.Series()**: ساخت یک سری (Series) از آرایه یا لیست  
  ```python
  import pandas as pd
  data = ['g', 'e', 'e', 'k', 's']
  ser = pd.Series(data)
  print(ser)
  ```
  خروجی:  
  ```
  0    g
  1    e
  2    e
  3    k
  4    s
  dtype: object
  ```
  همچنین می‌توان اندیس‌ها را به صورت دلخواه تعریف کرد:  
  ```python
  pd.Series([1., 2., 3.], index=['a', 'b', 'c'])
  ```

- **pd.DataFrame()**: ساخت دیتافریم از لیست یا دیکشنری  
  ```python
  data = [
    {'Scoville': 50, 'Name': 'Bell pepper', 'Feeling': 'Not even spicy'},
    {'Scoville': 5000, 'Name': 'Espelette pepper', 'Feeling': 'Uncomfortable'},
    {'Scoville': 500000, 'Name': 'Chocolate habanero', 'Feeling': 'Practically ate pepper spray'}
  ]
  df = pd.DataFrame(data)
  print(df)
  ```

- **loc و iloc**: انتخاب سطر و ستون بر اساس برچسب یا اندیس عددی  
  ```python
  df.loc[[5,7,9], ['Address', 'Type']]  # انتخاب سطرهای 5،7،9 و ستون‌های Address و Type
  df.iloc[[5,7,9], [1,2]]               # انتخاب سطرهای 5،7،9 و ستون‌های با اندیس 1 و 2
  ```

- **describe()**: نمایش آمار توصیفی ستون‌های عددی  
  ```python
  df.describe()
  ```
  برای ستون‌های غیرعددی نیز اطلاعات کلی می‌دهد.[2]

- **groupby()**: گروه‌بندی داده‌ها بر اساس یک یا چند ستون و اعمال توابع آماری  
  ```python
  df.groupby('column_name').mean()
  ```
  همچنین می‌توان تابع سفارشی برای گروه‌بندی تعریف کرد.[2][8]

- **fillna()**: جایگزینی مقادیر NaN با مقدار دلخواه  
  ```python
  df['column'].fillna(value, inplace=True)
  ```

- **apply()**: اعمال یک تابع دلخواه روی ستون یا ردیف‌ها  
  ```python
  df['column'].apply(lambda x: x+1)
  ```

- **drop_duplicates()**: حذف مقادیر تکراری  
  ```python
  df.drop_duplicates(inplace=True)
  ```

- **unique() و nunique()**: استخراج مقادیر یکتا و شمارش تعداد آن‌ها در یک ستون  
  ```python
  df['column'].unique()
  df['column'].nunique()
  ```

- **dtypes و columns**: مشاهده نوع داده ستون‌ها و نام ستون‌ها  
  ```python
  df.dtypes
  df.columns
  ```

این توابع از پرکاربردترین‌ها در pandas هستند و برای کار با داده‌ها بسیار مفیدند. اگر نیاز به مثال‌های بیشتر یا توضیح درباره هر کدام دارید، می‌توانم کمک کنم.
