
برخی از **توابع معروف و پرکاربرد NumPy** به همراه مثال به شرح زیر هستند:

| تابع | توضیح | مثال |
|-------|--------|-------|
| `np.sin()` | محاسبه سینوس زاویه (رادیان) | `np.sin(np.pi/2)` خروجی: 1.0 |
| `np.cos()` | محاسبه کسینوس زاویه | `np.cos(0)` خروجی: 1.0 |
| `np.tan()` | محاسبه تانژانت زاویه | `np.tan(np.pi/4)` خروجی: 1.0 |
| `np.exp()` | محاسبه توان e به توان x | `np.exp(1)` خروجی: 2.718... |
| `np.log()` | محاسبه لگاریتم طبیعی | `np.log(np.e)` خروجی: 1.0 |
| `np.sqrt()` | محاسبه ریشه دوم | `np.sqrt(16)` خروجی: 4.0 |
| `np.abs()` | مقدار مطلق | `np.abs(-5)` خروجی: 5 |
| `np.power(x, y)` | محاسبه x به توان y | `np.power(2, 3)` خروجی: 8 |
| `np.floor()` | گرد کردن به پایین | `np.floor(1.7)` خروجی: 1.0 |
| `np.ceil()` | گرد کردن به بالا | `np.ceil(1.2)` خروجی: 2.0 |
| `np.round()` | گرد کردن به تعداد ارقام اعشاری دلخواه | `np.round(2.345, 2)` خروجی: 2.35 |
| `np.min()` و `np.max()` | یافتن کمینه و بیشینه آرایه | `np.min([1][2][3])` خروجی: 1 |
| `np.mean()` | میانگین آرایه | `np.mean([1][2][3])` خروجی: 2.0 |
| `np.std()` | انحراف معیار | `np.std([1][2][3])` خروجی: 0.816... |
| `np.median()` | میانه | `np.median([1][3][2])` خروجی: 2.0 |
| `np.percentile()` | صدک | `np.percentile([1][2][3][4][5], 50)` خروجی: 3.0 |
| `np.linspace()` | تولید اعداد با فاصله مساوی در بازه مشخص | `np.linspace(0,1,5)` خروجی: [0. 0.25 0.5 0.75 1.] |
| `np.ones()` | ایجاد آرایه با مقدار ۱ | `np.ones((2,3))` خروجی: آرایه ۲ در ۳ با مقدار ۱ |
| `np.zeros()` | ایجاد آرایه با مقدار ۰ | `np.zeros(4)` خروجی: آرایه ۱ بعدی با ۴ صفر |
| `np.reshape()` | تغییر شکل آرایه | `np.reshape(np.arange(6), (2,3))` خروجی: آرایه ۲ در ۳ |
| `np.transpose()` | جابجایی سطر و ستون آرایه | `np.transpose([[1][2],[3][4]])` خروجی: [[1][3],[2][4]] |
| `np.sort()` | مرتب‌سازی آرایه | `np.sort([3][1][2])` خروجی: [1][2][3] |

### مثال ساده استفاده از چند تابع:

```python
import numpy as np

a = np.array([-1.7, 1.5, -0.2, 0.6, 10])

print("آرایه اولیه:", a)
print("گرد کردن به پایین:", np.floor(a))
print("گرد کردن به بالا:", np.ceil(a))
print("مقدار مطلق:", np.abs(a))
print("سینوس مقادیر:", np.sin(a))
```

خروجی:

```
آرایه اولیه: [-1.7  1.5 -0.2  0.6 10. ]
گرد کردن به پایین: [-2.  1. -1.  0. 10.]
گرد کردن به بالا: [-1.  2. -0.  1. 10.]
مقدار مطلق: [ 1.7  1.5  0.2  0.6 10. ]
سینوس مقادیر: [-0.99166481  0.99749499 -0.19866933  0.56464247 -0.54402111]
```
